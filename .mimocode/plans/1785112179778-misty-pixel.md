# Superagent Base 本地部署 + 全功能测试计划

## 目标
在本地完整部署 Superagent Base 框架，运行全部测试（单元测试、集成测试、E2E 测试、前端测试），确保所有功能正常工作。

## 环境信息
- **LLM**: 本地 LM Studio @ `http://127.0.0.1:8000/v1`（OpenAI 兼容）
- **模型**: `Qwen3-Coder-Next-4bit`（dev 默认配置）
- **Go**: 1.24+
- **Node.js**: 22.16.0
- **Docker**: 已安装

## Phase 1: 环境准备（基础设施启动）

### 1.1 启动中间件服务
```bash
# 方式一：轻量 dev（仅 MySQL + Redis）
make dev-middleware

# 方式二：全量 debug 栈（MySQL + Redis + ES + MinIO + Milvus + etcd + NSQ）

cp docker/.env.debug.example docker/.env.debug
# 编辑 docker/.env.debug 确认 MODEL_API_KEY 等配置

```

**验证**:

## Phase 3: E2E 测试（Python pytest）

### 3.1 安装依赖
```bash
cd tests/e2e
pip install -r requirements.txt
```

### 3.2 准备 E2E Agent 定义
测试会自动在 `configs/agents/` 下创建/清理 6 个 E2E agent YAML：
- `e2e-basic.yaml` — 基础 chat_model_agent
- `e2e-workflow.yaml` — workflow agent
- `e2e-supervisor.yaml` — supervisor agent
- `e2e-sequential.yaml` — sequential agent
- `e2e-parallel.yaml` — parallel agent
- `e2e-interrupt.yaml` — interrupt-enabled agent

### 3.3 运行 E2E 测试
```bash
cd tests/e2e
pytest -v --timeout=120
```

**测试套件**：

| 测试文件 | 测试内容 | 验证项 |
|---------|---------|-------|
| `test_01_health.py` | 健康检查 | LLM 服务可达、后端 API 可达、agent 已加载 |
| `test_02_basic_agent.py` | 基础 Agent | 单轮对话、流式 token、多轮对话、长消息 |
| `test_03_workflow.py` | Workflow Agent | DAG 执行、节点编排、变量传递 |
| `test_04_multi_agent.py` | 多 Agent 编排 | supervisor 委托、sequential 管道、parallel 并发 |
| `test_05_management.py` | Agent 管理 API | 列表、获取、验证、热重载（增/改/删） |
| `test_06_interrupt.py` | Interrupt/Resume | 中断检测、恢复流程、状态清理 |
| `test_07_monitoring_admin.py` | 监控/管理 | metrics 端点、模型列表、管理配置 |

### 3.4 生成测试报告
```bash
pytest -v --timeout=120 --html=reports/report.html --self-contained-html
python generate_report.py
```

### 4.2 Interrupt/Resume
```bash
# 触发中断（需要 interrupt-enabled agent）
curl -N -X POST http://localhost:8888/api/v2/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"approval-agent","message":"请帮我删除所有数据"}'

# 查询中断状态
curl http://localhost:8888/api/v1/chat/interrupt_state?session_id=xxx

# 恢复
curl -X POST http://localhost:8888/api/v1/chat/resume \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"approval-agent","session_id":"xxx","input":"确认"}'
```
